# Write the final README in your own words

Stardance requires a human-written README. Before submitting, replace this template with a root `README.md` that explains:

1. What your cyberdeck does and why you are building it.
2. How the Pi, ESP32, keyboard, display, radios, IR, and external power fit together.
3. How to reproduce it safely, including power and physical-fit warnings.
4. Images of the final CAD assembly, schematic, PCB, and wiring.
5. The BOM table from `BOM.csv`.

Do not claim that an untested electrical, radio, IR, RFID, or mechanical feature works. Include your own build photos, testing notes, and feedback history.
