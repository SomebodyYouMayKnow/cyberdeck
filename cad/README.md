# CAD sources

These files are copied from the active design folder for publication:

- `Cyberdeck_Enclosure.scad` is the editable parametric enclosure concept.
- `Cyberdeck_Fusion_Layout.dxf` is the millimetre placement sketch for Fusion.
- `Cyberdeck_layout.svg` is a visual layout reference.
- `MECHANICAL_VALIDATION.md` lists source dimensions and physical tests.

There is no final STEP assembly yet. Do not represent these sources as a fit-tested enclosure.
